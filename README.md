# Secondhand

A small buy-and-sell used-products app built with HTML, CSS, and JavaScript.

## Pages

- `index.html` — browse, search, filter, and sort listings
- `product.html` — product details and save action
- `sell.html` — publish a listing
- `saved.html` — saved products
- `messages.html` — buyer/seller messages
- `profile.html` — manage your listings

## Run

Open `index.html` in a browser.

Listings, saved products, and messages are stored in browser local storage.
